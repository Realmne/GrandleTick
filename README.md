# GrandleTick

GrandleTick 是一个运行在 macOS 菜单栏中的个人学习时间记录工具。

它会根据当前使用的应用、浏览器网页和 PDF 文档自动累计时间，把活动区分为学习与休闲，再通过数据中心帮助你回看一段时间里真正发生了什么。整个过程不需要手动开始或停止计时。

这个项目来自个人学习需求，不是商业软件，也不打算把简单的计时包装成复杂的“效率系统”。它关注的是三件事：自动记录、尽量准确、本地保存。

## 主要功能

### 自动记录当前活动

- 监听前台应用和窗口变化，切换内容后自动结束上一段记录并开始下一段
- 记录常规 macOS 应用的使用时间，并排除访达、Dock、控制中心、通知中心等系统界面
- 以事件变化驱动窗口识别，常驻菜单栏时不需要持续高频扫描
- 自动合并连续活动，定期保存当前会话，应用退出时也会写入尚未落库的时间

GrandleTick 会将活动分为两类：

| 分类 | 判断方式 |
| --- | --- |
| 学习 | 白名单应用、白名单网站、预览中的 PDF，以及被识别为知识分区的 Bilibili 视频 |
| 休闲 | 其他可识别的普通前台应用、非白名单网页、预览中的非 PDF 内容，以及 Bilibili 非知识分区视频 |

白名单决定一项活动是否计入“学习”，而不是决定软件是否记录所有普通前台活动。学习榜、学习趋势等学习指标会排除休闲记录，数据中心中仍可查看学习与休闲的整体分布。

### 浏览器与网站

目前支持：

- Safari
- Google Chrome
- Microsoft Edge

浏览器记录会读取当前标签页的地址和标题：

- 命中域名白名单时计入学习
- 未命中白名单时计入休闲
- 支持按域名聚合，避免同一网站的不同页面被拆成大量零散项目
- 支持按应用、域名或具体内容查看排行与明细

默认域名白名单包括 Bilibili、ChatGPT、OpenAI、豆包、腾讯元宝、Gemini、Claude 和 DeepSeek；可以按自己的学习方式增删。

#### Bilibili 识别

Bilibili 使用单独的识别规则：

- 从视频地址提取 BV 号
- 通过 Bilibili 公开接口读取视频标题和分区信息
- 知识分区视频保留具体标题，并按 BV 号累计
- 非知识分区视频统一归入休闲，避免进入学习榜和学习时长

这套规则用于减少娱乐视频被误算为学习，但分区本身并不等同于内容用途，因此结果仍可能与个人判断不同。

### PDF 阅读

- 自动识别 macOS「预览」中打开的 PDF
- 按 PDF 文档聚合阅读时间
- 使用文件标识与内容特征生成文档身份，文件重命名后仍能尽量延续原有统计
- 预览中打开图片或其他非 PDF 内容时，不计入 PDF 学习时间

当前只对系统自带的「预览」做了 PDF 专门识别，其他阅读器可作为普通应用加入白名单，但不会获得同样的文档级统计。

### 菜单栏状态

菜单栏弹层用于查看当前状态和完成常用操作：

- 菜单栏直接显示今日累计时长
- 显示当前窗口处于“学习中”“休闲中”还是“已暂停统计”
- 显示当前应用、网页、视频或 PDF 的累计时长
- 分别展示今日学习累计与今日休闲累计
- 快速打开白名单管理和数据中心
- 可在确认后清空全部历史记录

白名单管理和数据中心会在独立窗口中打开，关闭后应用继续以菜单栏方式运行。

### 定时休息

- 提供 25、45、60 分钟快捷选项
- 支持输入 1～720 分钟的自定义时长
- 菜单栏弹层中显示剩余时间，也可随时取消
- 到点后在当前屏幕右上角显示提醒，不抢占正在使用应用的键盘焦点
- 可完成休息或延后 5 分钟
- 倒计时使用绝对截止时间；Mac 睡眠、系统时间变化或应用重启后会重新校准

休息提醒是一个独立的倒计时工具，不会替代或修改活动统计结果。

### 数据中心

数据中心支持今天、本周、本月、今年和全部历史五种范围。除全部历史外，其余范围都可以前后翻页，查看过去的完整周期。

可以查看：

- 总学习时长、日均学习、活跃天数和最长连续学习天数
- 与上一周期的时长、学习天数和变化率对比
- 学习与休闲占比
- PDF、网页和普通应用的学习来源分布
- 每日学习趋势与单日最高学习时长
- 24 小时学习分布、主要学习时段、最早开始和最晚结束时间
- 应用学习时长占比
- 常用网站与常用 PDF
- 按应用、域名和具体窗口内容生成的学习排行

数据中心还提供：

- 搜索应用、域名、标题或链接
- 按网页 / PDF、应用和域名筛选
- 点选日期查看当天明细
- 按应用、域名和 PDF 展开明细
- 通过明细右键菜单删除对应记录

### 年度报告

年度报告是数据中心内的一组八页本地统计卡片，内容包括：

- 全年学习时长、活跃天数和日均学习
- 与上一年的对比
- 学习与休闲比例
- 24 小时学习节奏、最早开始和最晚结束时间
- 常用应用、网站和 PDF
- 最长连续学习天数、单日最高与最低学习记录
- 根据全年记录归纳的学习类型

年度报告只读取本地数据库，不会上传或分享记录。

## 系统要求

- macOS 14.0 或更高版本
- 首次使用需要授予“辅助功能”权限
- 浏览器统计需要使用 Safari、Google Chrome 或 Microsoft Edge
- PDF 文档级统计需要使用 macOS 自带的「预览」

辅助功能权限用于读取当前前台应用、窗口标题和浏览器标签页信息。没有该权限时，GrandleTick 无法识别正在使用的内容，也不会正常累计时间。

权限入口：

`系统设置 → 隐私与安全性 → 辅助功能`

## 安装

### 下载已构建版本

1. 前往 [GitHub Releases](https://github.com/YohanJx/GrandleTick/releases) 下载最新版本
2. 将 `GrandleTick.app` 放入 `/Applications`
3. 打开应用并按提示授予辅助功能权限
4. 点击菜单栏时钟图标，确认当前内容已经被正确识别

如果 macOS 提示“App 已损坏，打不开”，可以在终端执行：

```bash
sudo xattr -cr /Applications/GrandleTick.app
```

然后重新打开应用。

### 从源码构建

项目使用 SwiftUI、SwiftData 和 Swift Charts，最低部署目标为 macOS 14.0。

1. 克隆仓库
2. 使用 Xcode 打开 `GrandleTick.xcodeproj`
3. 选择本机作为运行目标
4. 构建并运行

如果签名配置与本机开发者账号不同，需要先在 Xcode 中调整 Signing & Capabilities。

## 开始使用

1. 启动 GrandleTick，并允许它访问辅助功能
2. 打开菜单栏弹层，检查当前应用和窗口标题是否正确
3. 进入“管理白名单”，添加需要计入学习的应用和域名
4. 正常使用电脑，GrandleTick 会自动记录学习与休闲时间
5. 打开“数据中心”查看趋势、排行和具体明细

建议先使用一段时间，再根据实际记录调整白名单。白名单过宽会把普通浏览算成学习，过窄则会让有效活动落入休闲。

## 白名单规则

默认应用白名单：

- 预览
- Safari
- Google Chrome
- Microsoft Edge

应用白名单用于判断普通本地应用是否属于学习；域名白名单用于判断浏览器网页是否属于学习。Safari、Google Chrome 和 Microsoft Edge 虽然也列在默认应用白名单中，但网页最终以域名规则为准。

白名单管理支持：

- 从“应用程序”目录选择并添加 App
- 手动输入域名；`http://`、`https://`、`www.` 和末尾斜杠会被自动整理
- 删除默认项或自定义项
- 将已经删除的默认项重新添加回来

白名单变化会影响统计时对历史记录的分类。例如把某个应用加入学习白名单后，它已有的本地活动记录可能会在重新统计时归入学习。

## 数据与隐私

GrandleTick 不需要账号，也没有自建服务器或云同步功能。

活动数据保存在：

```text
~/Library/Application Support/GrandleTick/ActivityData.sqlite
```

白名单和休息提醒截止时间保存在 macOS 的 `UserDefaults` 中。

本地活动记录可能包含：

- 应用名称与 Bundle 标识
- 窗口或文档标题
- 浏览器域名、页面地址与页面标题
- Bilibili 视频标识与分区信息
- PDF 文档标识
- 活动开始时间、结束时间和持续时长

这些记录不会上传到 GrandleTick 的服务器。使用 Bilibili 视频时，应用会向 Bilibili 公开接口请求对应 BV 号的标题和分区元数据，这是当前版本唯一的主动网络请求。

删除数据的方式：

- 在数据中心对具体明细使用右键菜单，删除对应记录
- 在菜单栏弹层选择“清空全部数据”，输入确认文字后删除全部历史
- 完全退出应用后，自行备份或删除上述数据库文件

## 当前边界

- 仅支持 macOS 14.0 及以上版本
- 需要辅助功能权限，无法在受限权限下完成核心记录
- 浏览器标签页地址读取只支持 Safari、Google Chrome 和 Microsoft Edge
- PDF 文档级统计只支持「预览」
- Bilibili 分类依赖视频分区和公开接口，不能保证符合每个人对学习内容的判断
- 非白名单的普通前台活动会作为休闲记录保存在本地；如果不希望保留，可从明细中删除或清空历史
- 当前没有多设备同步、账号体系、手动计时项目、待办事项或团队功能
- 项目围绕个人学习工作流维护，不以覆盖所有时间追踪场景为目标

## 常见问题

### 为什么没有开始统计？

先检查菜单栏弹层中的状态：

- 如果提示需要权限，请前往系统设置授予辅助功能权限
- 如果显示“已暂停统计”，当前内容可能是系统界面、无有效窗口，或暂时无法读取
- 如果是浏览器，确认使用的是受支持的浏览器，并且标签页已经完成加载
- 如果是 Bilibili，视频元数据首次读取期间可能需要短暂等待

### 为什么网页或应用被算进了休闲？

学习分类由白名单决定。请检查：

- 应用是否在应用白名单中
- 浏览器当前域名是否在域名白名单中
- Bilibili 视频是否属于当前识别规则中的知识分区
- 预览中打开的是否确实是 PDF

### 修改白名单会影响以前的数据吗？

会影响统计分类。原始活动仍保存在本地，数据中心会按照当前白名单重新判断哪些活动属于学习。

### 为什么同一个 PDF 改名后仍合并在一起？

GrandleTick 会使用文件标识和部分内容特征识别 PDF，而不只依赖文件名。这是为了让重命名后的文档尽量延续原有累计时间。

### 休息倒计时在 Mac 睡眠时会暂停吗？

不会简单暂停。倒计时保存的是截止时间，Mac 唤醒或应用重新启动后会按当前时间重新计算；如果已经到点，会补发提醒。

### 数据会同步到云端吗？

不会。当前版本只做本地存储，也没有账号或同步功能。

### 如何彻底删除记录？

可以在菜单栏弹层中清空全部历史。也可以退出 GrandleTick 后删除：

```text
~/Library/Application Support/GrandleTick/ActivityData.sqlite
```

## 项目说明

GrandleTick 是从个人学习流程中逐步完善出来的工具。它不提供商业服务承诺，也不把使用时长本身视为学习质量；记录的作用只是让回顾更具体。

如果你的学习方式接近“网页课程、PDF 阅读和日常应用混合使用”，可以直接尝试。如果需要不同的分类标准、更多浏览器或其他阅读器，也可以基于源码继续调整。
